# PROYECT-WATCH

Beta interna: web interactiva que explica el funcionamiento de un reloj
mecánico, explosionando sus piezas en 3D a medida que se hace scroll.

**No es un proyecto público.** Ver `CLAUDE.md` para el plan, la arquitectura
y el estado de las fases.

## Desarrollo

```bash
npm install
npm run dev
```
